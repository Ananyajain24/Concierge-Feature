# Lohono Concierge - System Requirements & Setup

## System Requirements (No Docker)

### 1. Node.js
- Required Version: >= 20
- Download: https://nodejs.org/
- Verify: `node --version`

### 2. PostgreSQL
- Required Version: >= 16
- Download: https://www.postgresql.org/download/
- For Windows: Use PostgreSQL installer or use pgAdmin for GUI management
- Verify: `psql --version`
- Start PostgreSQL service (Windows: PostgreSQL should auto-start as service)

### 3. pnpm (Package Manager)
- Required Version: 9.12.0
- Install: `npm install -g pnpm`
- Verify: `pnpm --version`

### 4. API Keys
- Anthropic API: https://console.anthropic.com/
  - Get key at https://console.anthropic.com/account/keys
- Gemini API (optional): https://aistudio.google.com/apikey
